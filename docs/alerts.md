# แจ้งเตือนเข้า LINE

หลังบ้าน → **แจ้งเตือน** ส่งข้อความหาคุณเองเมื่อมีลูกค้าใหม่ หรือเมื่อระบบล่ม
คนละเส้นกับข้อความที่ลูกค้าได้รับ

## โควตา

LINE ให้ส่งข้อความหาคนอื่นฟรี **300 ข้อความต่อเดือน** (การตอบลูกค้าไม่นับ นับเฉพาะที่เราส่งเอง)
ระบบตั้งเพดานไว้ที่ 250 เผื่อไว้สำหรับเรื่องด่วน ถ้าถึงเพดานจะหยุดส่งและขึ้นให้เห็นในหน้าแจ้งเตือน

## ผูกบัญชี LINE ครั้งเดียว

1. หลังบ้าน → แจ้งเตือน → **ขอรหัสผูกบัญชี**
2. เปิดแชท LINE กับ **advisortool.app** แล้วส่งรหัสนั้น (เช่น `ALERT-4F2K9`) ภายใน 10 นาที
3. บอทตอบยืนยัน เสร็จแล้ว

ที่ต้องทำแบบนี้เพราะการส่งข้อความหาใครใน LINE ต้องรู้รหัสผู้ใช้ของคนนั้น ซึ่งไม่มีหน้าไหนแสดง
บัญชีที่ส่งรหัสถูกคือบัญชีที่ได้รับแจ้งเตือน

## แจ้งเมื่อมีลูกค้าใหม่

เลือกได้สามแบบ

| แบบ | แจ้งเมื่อ | ใช้โควตา |
| --- | --- | --- |
| เฉพาะคนที่ขอดูเบี้ย (ค่าเริ่มต้น) | บอทตอบเบี้ยให้ลูกค้า | น้อยที่สุด |
| ทุกคนที่ทักเข้ามา | ใครก็ตามเริ่มบทสนทนาใหม่ | เร็วขึ้นมาก |
| ไม่ต้องแจ้ง | ปิด (ยังแจ้งเรื่องระบบล่มอยู่) | ไม่ใช้ |

แจ้ง **หนึ่งครั้งต่อหนึ่งบทสนทนา** ลูกค้าคนเดิมถามสามรอบก็ยังแจ้งครั้งเดียว

ข้อความแจ้งเตือนบอกแค่ว่าถามอะไรและบอทตอบอะไร ไม่มีชื่อหรือสิ่งที่ระบุตัวตน
เพราะระบบเก็บผู้ใช้เป็นรหัสแฮชอยู่แล้ว จึงไม่ขัดกับนโยบายความเป็นส่วนตัวที่ประกาศไว้ว่าเก็บบทสนทนา 24 ชั่วโมง

## แจ้งเมื่อระบบล่ม

แอปที่ล่มแล้วบอกตัวเองไม่ได้ ต้องมีตัวเฝ้าจากข้างนอก

**หน้าเช็คสุขภาพ**

```
GET https://www.advisortool.app/api/health
```

ตอบ 200 พร้อม `{"ok":true,...}` เมื่อปกติ และ 503 เมื่อมีอะไรเสีย ไม่มีความลับอยู่ในคำตอบ

> **เคยมีปัญหา** ระบบป้องกัน DDoS อัตโนมัติของ Vercel เคยจับโดเมนนี้ไว้ ทำให้ทุกคำขอที่ไม่ใช่
> เบราว์เซอร์ได้ 403 รวมถึงเว็บฮุกและตัวเฝ้า แก้ด้วยกฎ firewall ชื่อ
> "Bypass challenge on advisortool.app" (เผยแพร่ 6 ก.ย. 2569) ถ้าวันหนึ่งอาการกลับมา
> ให้ตรวจว่ากฎนี้ยังอยู่ไหมด้วย `npx vercel firewall overview`

> เคสจริงที่เคยเกิด 4 ก.ย. 2569 Vercel เปิดระบบกันบอท เว็บยังเปิดดูได้ปกติแต่ LINE กับ Meta
> ยิงเข้ามาไม่ได้ บอททั้งสองตัวหยุดตอบลูกค้าโดยไม่มีใครรู้ หน้านี้จะจับได้ เพราะตัวเฝ้าก็เป็นบอทเหมือนกัน

**ให้แจ้งเข้า LINE** ตัวเฝ้ายิงกลับมาที่

```
POST https://www.advisortool.app/api/alerts/notify
x-alert-secret: <ค่าใน ALERT_WEBHOOK_SECRET>
{"text":"เว็บไม่ตอบมา 5 นาที"}
```

### ตั้งด้วย UptimeRobot (ฟรี)

1. Add New Monitor → HTTP(s) → URL `https://www.advisortool.app/api/health` → ทุก 5 นาที
2. Alert Contacts → เพิ่ม Webhook ชี้มาที่ `/api/alerts/notify` ใส่หัวข้อ `x-alert-secret`

### ตั้งด้วย n8n

Schedule Trigger (ทุก 5 นาที) → HTTP Request ไป `/api/health` → IF `status != 200`
→ HTTP Request POST ไป `/api/alerts/notify` พร้อมหัวข้อ `x-alert-secret`

n8n รันบน Vercel ไม่ได้ ต้องมีเซิร์ฟเวอร์ที่เปิดตลอด เช่น PikaPods (~130 บาท/เดือน)
หรือ n8n Cloud (ทดลองฟรี 14 วัน) ถ้าต้องการแค่ข้อ 1 นี้ UptimeRobot ฟรีก็พอแล้ว
