# สร้างคอนเทนต์ — แบบระบบ (รอบ 1: ข้อความ)

วันที่ 2026-09-23 · สถานะ: รอเจ้าของอ่านทวน

## เป้าหมาย

เลือกผลิตภัณฑ์ในระบบ แล้วกดปุ่มเดียวได้ **โพสต์เฟซบุ๊ก** หรือ **สคริปต์พูดหน้ากล้อง** ที่เขียนจากข้อมูลจริงของแบบนั้น
ตัวเลขทุกตัวมาจากตารางเบี้ย ไม่ใช่จากความจำของ AI

## สิ่งที่ตัดสินใจแล้ว

| เรื่อง | ตัดสินใจ |
|---|---|
| ผู้ใช้ | เจ้าของคนเดียว (ตัวแทนในทีมค่อยเปิดทีหลัง ไม่ต้องรื้อ) |
| ที่อยู่ | `/content` ในเมนูหลัก ต่อจาก "ถาม AI" — ทุกคนเห็น เจ้าของรับทราบแล้ว |
| เก็บประวัติ | เก็บ ติดดาวได้ |
| รูปภาพ | **ไม่อยู่ในรอบนี้** — รอบ 2 (Gemini Image) AI รอบนี้เขียน "คำสั่งวาดรูป" เก็บไว้ให้ก่อน |
| ตรวจภาษา | ชั้น 1 ระบบตรวจเอง + ชั้น 2 AI ตรวจทาน |

## ผลิตภัณฑ์ที่เลือกได้

ทุกแบบที่มีหน้าขายใน `SALES_SECTIONS` (`src/lib/shell/menu.ts`) **ยกเว้นประกันกลุ่ม** —
เจ้าของเคยตัดสินใจว่าประกันกลุ่มขายผ่านคน ไม่ให้ AI บรรยาย (ดู `knowledge.ts`) จึงไม่ให้ AI เขียนโฆษณาด้วย

Life Protect x 2 · Protection Life · Easy Protect 6 · Life Treasure · Family Legacy · iShield · CI 123 · Cancer · iHealthy Ultra · bumnan95

## หน้าจอ `/content`

1. เลือก **ผลิตภัณฑ์**
2. เลือก **ประเภท**: โพสต์เฟซบุ๊ก / สคริปต์วิดีโอ
3. เลือก **มุมเล่า** (ไม่บังคับ): คุ้มครองครอบครัว · ลดหย่อนภาษี · ซื้อให้ลูก · เกษียณ · เรื่องเล่าลูกค้า · พิมพ์เอง
4. ถ้าเป็นวิดีโอ เลือก **ความยาว**: 30 วิ · 60 วิ · 2–3 นาที
5. กด **สร้าง** →
   - **ประโยคเปิด 3 แบบ** ให้เลือก 1
   - เนื้อหา · ประโยคปิด/ชวนทัก · แฮชแท็ก (เฉพาะโพสต์)
   - ข้อความเตือน คปภ. ต่อท้ายเสมอ
   - ทุกช่องแก้ได้ · ปุ่ม คัดลอกทั้งชิ้น / สร้างใหม่ / ติดดาว
6. แถบเตือนสีเหลือง (ถ้ามี): ตัวเลขที่ไม่ตรงตาราง · คำต้องห้าม · จุดที่ AI ตรวจทานเสนอแก้ (กดรับทีละจุด)
7. ด้านล่าง: **ที่เคยสร้าง** — กรองตามผลิตภัณฑ์ · เฉพาะที่ติดดาว

สคริปต์วิดีโอแบ่งช่วงพร้อมเวลา `[0–3 วิ]` `[เนื้อหา]` `[ปิด]` และมีวงเล็บบอกท่าทาง/ข้อความขึ้นจอ

## การทำงานเบื้องหลัง

```
เลือก → ข้อมูลจริงของแบบ ─┐
                         ├→ AI เขียน (1 ครั้ง) → ชั้น 1 ระบบตรวจ → แสดงผล + บันทึก
          คำสั่งเขียน ───┘                                  └→ ชั้น 2 AI ตรวจทาน → ไฮไลต์เพิ่ม
```

### 1. ข้อมูลจริงของแบบ — `src/lib/content/brief.ts`

ฟังก์ชันเดียว `briefFor(planHref)` คืน:
- **กฎและเงื่อนไข** — จากคลังความรู้เดียวกับบอท (`assembleKnowledge` / กฎรายแบบ)
- **ตัวเลขที่อนุญาต** — จาก `*Facts()` ของแต่ละแบบ (`lifeProtectFacts`, `plbFacts`, …)
  CI 123 และ Cancer ยังไม่มีไฟล์ facts → ดึงจาก `ci123-cta.ts` / `cancer-cta.ts` / ตารางของมัน
- **`allowedNumbers`** — รายการตัวเลขทุกตัวข้างบน ใช้ตรวจในชั้น 1
- ถ้าตารางเบี้ยหมดอายุ (`expired`) → ไม่ส่งราคาเลย และบอก AI ให้เขียนโดยไม่ใส่ราคา

### 2. AI เขียน — `src/lib/content/write.ts`

- เรียก `chat({ tier: "large", task: "content", json: true })` — **ครั้งแรกที่ระบบใช้ tier large**
  ลำดับ: Claude Sonnet 5 → GPT-5 → Gemini 3.7 Flash → GLM-5.3 (ตาม `TIER_PREFERENCE.large` และตัวที่เลือกในหน้าตั้งค่า)
- ได้ JSON: `{ hooks: [3], body, closing, hashtags, imagePrompt }` (สคริปต์: `body` เป็นช่วงพร้อมเวลา)
- คำสั่งเขียนห้าม: แต่งตัวเลข · คำเกินจริง · สัญญาผลตอบแทนที่ไม่การันตี · พูดถึงบริษัทอื่น
- **ข้อความเตือน คปภ. ต่อท้ายโดยโค้ด ไม่ใช่ให้ AI เขียน**:
  "ผู้ซื้อควรทำความเข้าใจรายละเอียดความคุ้มครองและเงื่อนไขก่อนตัดสินใจทำประกันภัยทุกครั้ง"
  (ข้อความเดียวกับหน้าขาย) + ถ้ามุมเล่าเป็นลดหย่อนภาษี เพิ่มบรรทัดเรื่องสิทธิทางภาษีตามกรมสรรพากร
- ค่าใช้จ่ายโดยประมาณ 0.5–1 บาท/ชิ้น — ตรวจราคาจริงจากตาราง model ก่อนเริ่ม

### 3. ชั้น 1 ระบบตรวจเอง — `src/lib/content/check.ts` (ฟังก์ชันล้วน ทดสอบได้)

- **ตัวเลข**: ดึงจำนวนเงิน/ทุน/เบี้ย/อายุ ทุกตัวในผลลัพธ์ เทียบ `allowedNumbers` → ตัวที่ไม่ตรง = เตือน
- **คำต้องห้าม / คำผิดบ่อย**: รายการตั้งต้นในไฟล์ (เช่น การันตี, ดีที่สุด, ได้เงินคืนแน่นอน, ไม่ต้องตรวจสุขภาพ)
  + รายการที่เจ้าของเพิ่มเองในตาราง `ins_content_words`
- แก้รายการคำได้ที่ **/admin/knowledge (สอน AI)** ส่วนใหม่ "คำต้องห้ามในโพสต์" — ไม่อยู่ในหน้าสาธารณะ

### 4. ชั้น 2 AI ตรวจทาน — `src/lib/content/proofread.ts`

- `chat({ tier: "small", task: "content-proofread", json: true })` ราว 0.05 บาท
- ได้ `[{ find, replace, why }]` — เสนอเฉพาะจุด ไม่เขียนใหม่ทั้งชิ้น
- รันอัตโนมัติหลังแสดงผลลัพธ์แล้ว (ผู้ใช้ไม่ต้องรอ) ถ้าล้มเหลว = ไม่มีไฮไลต์ ไม่ทำให้ชิ้นงานหาย

### 5. การกันงบ (หน้าสาธารณะ)

- `allow()` จาก `rate-limit.ts` ต่อ IP — จำกัดเข้มกว่าแชท (ค่าตั้งต้น 10 ชิ้น/ชม./เครื่อง)
- `assertWithinBudget` เดิม — ถึงเพดานเดือน = ขึ้นข้อความ "ใช้ครบงบเดือนนี้แล้ว"
- ทุกการเรียกลงบันทึกค่าใช้จ่ายเดิม (`task = content` / `content-proofread`) เห็นใน /admin/ai

## ฐานข้อมูล (migration ใหม่ 1 ไฟล์)

ล็อกให้ `service_role` เท่านั้นเหมือนตาราง `ins_*` ทั้งหมด — หน้าเว็บเข้าผ่าน server action

**`ins_content`**
`id uuid pk` · `created_at` · `plan_href text` · `format text ('post'|'script')` · `angle text` · `length text null`
· `output jsonb` (hooks, chosen_hook, body, closing, hashtags, image_prompt, disclaimer)
· `flags jsonb` (ตัวเลขไม่ตรง, คำต้องห้าม, ข้อเสนอตรวจทาน) · `rate_version text` · `model text` · `cost_thb numeric` · `starred bool default false`

**`ins_content_words`**
`word text pk` · `kind text ('banned'|'misspelling')` · `fix text null` · `created_at`

## การทดสอบ

- `check.ts`: ตัวเลขตรง/ไม่ตรง (รวมรูปแบบ 1,000 / 1 พัน / 1K) · คำต้องห้าม · ไม่มีเตือนเมื่อสะอาด
- `brief.ts`: ทุกแบบในรายการคืน brief ได้ · ตารางหมดอายุ = ไม่มีราคา · ประกันกลุ่มไม่อยู่ในรายการ
- `write.ts`: JSON เสีย/ขาดช่อง → error ภาษาไทยที่อ่านรู้เรื่อง · disclaimer ต่อท้ายเสมอ
- `menu.ts`: เมนูใหม่เห็นทั้งหน้าลูกค้าและหลังบ้าน
- ทดลองจริงบนเบราว์เซอร์ อย่างน้อย Life Protect (โพสต์) และ iHealthy (สคริปต์ 60 วิ)
- ทุก commit ผ่าน `npm run verify` ก่อน
