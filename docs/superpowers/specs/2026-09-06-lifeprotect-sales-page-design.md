# เซลล์เพจ Life Protect+ 100 — เอกสารออกแบบ

วันที่: 2026-09-06
สถานะ: ผู้ใช้อนุมัติแบบร่างแล้ว

หน้า `/legacy` ขายชุด "มรดกเพื่อครอบครัว" (Life Protect+ 100 ทุน 150,000 จับคู่กับ DCI)
เอกสารนี้ออกแบบ **หน้าใหม่แยกต่างหาก** ที่ขายแบบประกันหลัก Life Protect+ 100 เดี่ยว ๆ
พร้อมตัวคำนวณของตัวเอง ไม่แตะพฤติกรรมของ `/legacy`

## 1. สิ่งที่ขาย

ไลฟ์ โพรเทค+ 100 (Life Protect x 2) ประกันชีวิตตลอดชีพ คุ้มครองถึงอายุ 99 ไม่มีสัญญาเพิ่มเติม
ลูกค้าเลือกได้ 3 งวดชำระ ซึ่งในระบบคือ 3 variant ของแผน `LIFEPROTECT`:

| งวดชำระ | variant | ระยะเวลาชำระ |
|---|---|---|
| จ่าย 9 ปี | `WLF09H` | 9 ปี |
| จ่าย 19 ปี | `WLF19H` | 19 ปี |
| จ่ายถึงอายุ 99 | `WLF99H` | 99 − อายุ ปี |

ไม่ขาย `WLF99HX` / `WLF99HX#7` (แพ็กเกจสุขภาพ) และไม่ขายรุ่น +50 (x 1.5)

ข้อเท็จจริงของแบบที่หน้าอ้างถึง ทั้งหมดมีในระบบแล้ว:
- รับอายุ 0–80 ทุนขั้นต่ำ 150,000 ไม่มีส่วนลดตามทุน (ตารางส่วนลดเป็นศูนย์ทุกขั้น)
- เสียชีวิตก่อนครบรอบปีกรมธรรม์ที่อายุ 60 จ่าย 2 เท่าของทุน (`extraDeathBenefitBeforeAge: 60`, `booster: 1`) ตั้งแต่อายุ 60 จ่ายเท่าทุน
- เบี้ยแบบหลักคงที่ตลอดระยะเวลาชำระ (เรตคิดจากอายุแรกเข้า ไม่ใช่อายุปัจจุบัน)
- มีตารางมูลค่าเวนคืนเงินสดครบทุกปีกรมธรรม์ใน `data/cash-values/lifeprotect.json`
- ขั้นต่ำงวดรายเดือน 1,000 บาท (`minMonthlyTotal`)
- ตารางเบี้ยฉบับ A2026-1 หมดอายุ 2027-03-31

## 2. คนที่หน้านี้พูดด้วย และจุดขาย

ลูกค้าเย็นจากแอด บนมือถือ เหมือน `/legacy` แต่โจทย์ต่างกัน: คนที่อยาก **ส่งต่อเงินก้อนที่แน่นอน** และไม่อยากจ่ายเบี้ยไปทั้งชีวิต
จุดขายหลักตอนออกแบบคือ **มรดกแน่นอน · เบี้ยคงที่ · จ่ายจบ** จุดขายรองคือ 2 เท่าก่อนอายุ 60 และซื้อให้ลูก

**ปรับ 2026-09-07 หลังผู้ใช้เห็นหน้าจริง:** สลับให้ **ทุนคูณสอง** เป็นแกนหลัก — พาดหัว "ทำทุนไว้ 1,000,000 / ครอบครัวได้ 2,000,000",
บรรทัดใต้แถบทุนโชว์ 2 เท่าทันที (คนอายุ 60 ขึ้นไปเห็น "คุ้มครองเท่าทุน" แทน), กรอบ "จ่ายเบี้ยจากทุน 1 ล้าน แต่ครอบครัวได้ 2 ล้าน" ย้ายมาต่อจากตัวคำนวณ,
บล็อกซื้อให้ลูกเน้นคูณสองถึงอายุ 60 ของลูก, คำถามที่พบบ่อยเปิดด้วย "ทำไมได้ 2 เท่า" และ "เริ่มตอน 60 ขึ้นไปยังได้ไหม", ข้อความกำกับเพิ่มเงื่อนไขของผลประโยชน์ 2 เท่า
เบี้ยคงที่และจ่ายจบยังอยู่ แต่เป็นข้อรอง

หน้านี้เป็นคู่ตรงข้ามของ `/legacy` โดยตั้งใจ: `/legacy` เพิ่มโรคร้ายแรงแต่เบี้ยส่วนนั้นขึ้นทุกปี หน้านี้ไม่มีโรคร้ายแรงแต่เบี้ยไม่ขยับเลย
คำถามที่พบบ่อยข้อหนึ่งอธิบายความต่างนี้และลิงก์ไป `/legacy`

- แก้เนื้อหาหรือพฤติกรรมของ `/legacy` และหน้า `/` ของตัวแทน

## 4. วิธีคิดเบี้ยในเบราว์เซอร์

`/legacy` คิดราคาทั้งหมดบนเซิร์ฟเวอร์เป็นตาราง 920 แถว เพราะโดเมนปิด (46 อายุ × 2 เพศ × 10 ขั้น)
หน้านี้มี 20 ทุน × 3 งวด × 2 เพศ × 81 อายุ × 3 งวดชำระเงิน ≈ 29,000 ตัวเลข ตารางแบบเดียวกันจะหนักราว 200 kB — ไม่เหมาะกับคนกดแอดบนมือถือ

แบบหลักไม่มีสัญญาเพิ่มเติม สูตรเบี้ยจึงเป็นฟังก์ชันล้วนที่ไม่ต้องพึ่ง registry:
`basePremium()` ใน `src/calc/base-premium.ts` รับ `PlanRates` แล้วคืนเบี้ยรายปี/รายงวดในหน่วยสตางค์ ปัดลงแบบเดียวกับ Excel
มันนำเข้าแค่ `lookup.ts`, `discount.ts`, `money.ts` — ไม่ลากตารางเบี้ยของแผนอื่นมาด้วย

เซิร์ฟเวอร์จึงสร้าง **`LifeProtectTable`** ชุดเล็กส่งให้เบราว์เซอร์:

```ts
interface LifeProtectTable {
  ageMin: number;            // 0
  ageMax: number;            // 80
  expired: boolean;          // ตารางเบี้ยหมดอายุแล้ว → ห้ามโชว์ราคา
  rateVersion: string;       // "A2026-1"
  minMonthly: number;        // 1000 บาท
  boosterBeforeAge: number;  // 60
  coverToAge: number;        // 99
  terms: Term[];             // 3 งวดชำระ เรียงตามที่แสดง
}
interface Term {
  variant: string;           // "WLF19H"
  label: string;             // "จ่าย 19 ปี"
  payTerm?: number;          // 9 | 19; ไม่มีเมื่อจ่ายถึงอายุ
  payToAge?: number;         // 99
  /** เรตต่อพัน [เพศ][อายุ − ageMin] */
  rates: Record<Sex, number[]>;
  /** ตัวคูณมูลค่าเวนคืน ณ อายุหลัก [เพศ][อายุ − ageMin] → { 60, 70, 80, 99 } ที่ยังมาไม่ถึง */
  cash: Record<Sex, (Record<number, number> | null)[]>;
  modeFactors: Record<PayMode, number>;
}
```

เบราว์เซอร์คิดเบี้ยด้วย `premiumPerThousand()` / `applyModeFactor()` จาก `money.ts` โดยตรง (ส่วนลดเป็นศูนย์ จึงไม่ต้องส่งตารางส่วนลด)
ฟังก์ชันที่คิดอยู่ใน `src/lib/lifeprotect-quote.ts` (ฟังก์ชันล้วน ไม่มี React) เพื่อให้เทสต์เทียบกับ `quote()` ของเครื่องคิดเลขตัวแทนได้ตรง ๆ ทุกกรณีที่สุ่ม

มูลค่าเวนคืน = `round(factor × ทุน / 1000)` เหมือน `cash-value.ts` ส่งเฉพาะตัวคูณ ณ อายุ 60 / 70 / 80 และค่าปลายตาราง (สิ่งที่ถืออยู่ตอนอายุ 99 ตาม `maturityValue()`) ไม่ส่งทั้งตาราง

`expired` ถามใหม่ทุกครั้งที่เรียก ส่วนที่เหลือ cache ในโปรเซสเหมือน `legacy-table.ts`

## 5. ตัวคำนวณ

### ช่องกรอก 4 ช่อง คำนวณใหม่ทันที ไม่มีปุ่ม "คำนวณ"
- **ทุนประกัน** แถบเลื่อน 500,000 → 50,000,000 ค่าเริ่มต้น 1,000,000 ตัวเลขที่เลือกโชว์ตัวใหญ่เหนือแถบ
  ขั้นละ 500,000 จนถึง 10 ล้าน แล้วขั้นละ 1,000,000 จนถึง 50 ล้าน (60 ขั้น) — ขั้นเดียวตลอดจะได้ 100 ขั้นซึ่งเลื่อนบนมือถือไม่ไหว (ผู้ใช้ขยายจาก 10 ล้านเป็น 50 ล้านหลังเห็นหน้าจริง 2026-09-06)
- **งวดชำระ** ปุ่ม 3 ปุ่มเรียงแนวนอน: จ่าย 9 ปี / จ่าย 19 ปี / ถึงอายุ 99 ค่าเริ่มต้น **ถึงอายุ 99** (ผู้ใช้สั่ง 2026-09-07 — เบี้ยต่อเดือนต่ำสุด และตรงกับตัวเลข "เริ่มต้นวันละ N บาท" บน Hero)
  เมื่อกรอกอายุแล้ว **แต่ละปุ่มแสดงเบี้ยรายปีของงวดนั้น** ลูกค้าเทียบสามแบบได้โดยไม่ต้องกดสลับ (รายปีเสมอ ไม่ตามตัวใหญ่บนการ์ด — ผู้ใช้ขอ 2026-09-06 หลังเห็นปุ่มปน /เดือน กับ /ปี เมื่องวดหนึ่งต่ำกว่าขั้นต่ำรายเดือน)
- **อายุ** ตัวเลือก (`<select>` เหมือน `/legacy`): 0 แสดงเป็น "แรกเกิด", 1–80 ปี, ปิดท้าย "81 ปีขึ้นไป" **ค่าเริ่มต้น 35 ปี** (ผู้ใช้สั่ง 2026-09-07) — คนที่กดแอดเข้ามาเห็นราคาจริงทันทีโดยไม่ต้องเลือกอะไรก่อน จึงไม่มีสถานะ "ยังไม่เลือกอายุ" อีก
- **เพศ** ชาย / หญิง ค่าเริ่มต้นชาย

### การ์ดผลลัพธ์ (เมื่อเลือกอายุ 0–80)
1. **เบี้ยตัวใหญ่** รายเดือนถ้าบริษัทรับ (≥ 1,000 บาท) ไม่งั้นรายปี — ใช้ `displayPremium()` เดิม
   ตามด้วย "ตกวันละ N บาท" (`perDay()` เดิม) และงวดอื่นที่รับได้ตัวเล็ก
2. **จ่ายทั้งหมดกี่ปี รวมเบี้ยเท่าไหร่** — "จ่าย 19 ปี รวมประมาณ 545,300 บาท · คุ้มครอง 1,000,000 บาทถึงอายุ 99"
   รวมเบี้ย = เบี้ยรายปี × จำนวนปี (แบบถึง 99 ใช้ 99 − อายุ) ทำได้เพราะเบี้ยแบบหลักคงที่จริง
3. **ครอบครัวได้รับ** ใช้ `deathBenefitRows()` เดิม: "เสียชีวิตก่อนอายุ 60 ปี" 2 เท่าของทุน / "อายุ 60 ปีขึ้นไป" เท่าทุน
   คนอายุ 60 ขึ้นไปเห็นบรรทัดเดียว "ทุกช่วงอายุ"
4. **มูลค่าเงินสดสะสม (หากเวนคืน)** อายุ 60 / 70 / 80 / 99 เฉพาะอายุที่มากกว่าอายุลูกค้า ปีที่มูลค่าเป็นศูนย์ไม่แสดง
5. อายุ 0–15: บรรทัดสั้น "เบี้ยล็อกที่อายุนี้ตลอดระยะเวลาชำระ ยิ่งเริ่มเร็วยิ่งถูก"
6. บรรทัดกำกับในการ์ด: "เบี้ยคงที่ตลอดระยะเวลาชำระ · เบี้ยมาตรฐาน อาจต่างไปตามผลพิจารณารับประกัน"

### กรณีที่ราคาต้องไม่ปรากฏ หรือปรากฏต่างไป
- **81 ปีขึ้นไป** — การ์ดเปลี่ยนเป็น "แบบนี้รับถึงอายุ 80 ปี ทักมาให้เราช่วยหาแบบที่เหมาะกับคุณ" ปุ่มทักยังอยู่
- **รายเดือนต่ำกว่า 1,000 บาท** — ซ่อนงวดรายเดือน ตัวใหญ่ใช้รายปี (เกิดบ่อยกับเด็กและทุน 5 แสน เช่น แรกเกิด ทุน 1 ล้าน จ่ายถึง 99 รายเดือน 540 บาท)
- **ตารางเบี้ยหมดอายุ** — ซ่อนเบี้ยทุกตัวรวมทั้งบนปุ่มงวดและรวมเบี้ย การ์ดแสดง "ขอราคาปัจจุบันได้ทางแชทด้านล่าง" ผลประโยชน์และมูลค่าเงินสดยังแสดง เพราะไม่ขึ้นกับตารางเบี้ย
- **ไม่มีเรตสำหรับอายุนั้น** (ไม่ควรเกิด เพราะทุกงวดรับ 0–80) — ปฏิบัติเหมือน 81 ปีขึ้นไป

### ปุ่มทัก
`ContactButtons` ตัวเดิมย้ายมาเป็นคอมโพเนนต์กลาง ใช้ `legacyChannels()` เดิมหาช่องทาง แถบติดขอบล่างบนมือถือเหมือนเดิม
**หน้านี้ไม่มีปุ่ม "ถาม AI"** (ผู้ใช้สั่ง 2026-09-07) มีเฉพาะ LINE กับ Messenger ที่คนตอบ `/legacy` ยังมีปุ่ม AI ตามเดิม
ข้อความสร้างโดย `lifeProtectMessage()` ใน `src/lib/lifeprotect-cta.ts`:

```

81 ขึ้นไป:      สนใจ Life Protect+ 100 ทุน 1,000,000 อายุเกิน 80 ปี ขอแบบที่เหมาะกับอายุนี้
ไม่มีราคา:      สนใจ Life Protect+ 100 ทุน 1,000,000 จ่าย 19 ปี อายุ 35 ชาย ขอราคาปัจจุบัน
แรกเกิด:        … อายุแรกเกิด ชาย …
```

งวด "ถึงอายุ 99" เขียนในข้อความว่า "จ่ายถึงอายุ 99"

> เลือกจ่าย 9 ปี 19 ปี หรือถึงอายุ 99 เบี้ยเท่าเดิมทุกปี คุ้มครองถึงอายุ 99 **เสียชีวิตก่อน 60 ครอบครัวได้ 2 เท่า**
>
> `[ ดูเบี้ยของฉัน ↓ ]`
> อายุ 35 เริ่มต้นวันละ N บาท · รับแรกเกิด–80 ปี · ไม่ต้องกรอกเบอร์

"วันละ N บาท" มาจากหญิง 35 ทุน 500,000 จ่ายถึงอายุ 99 (ทุนต่ำสุด งวดถูกสุด ตัวเลขที่ซื่อสัตย์ที่สุดที่โฆษณาได้) เป็น null เมื่อตารางหมดอายุ

### บล็อก 3 — ทำไมต้องแบบนี้
> ## ประกันที่จ่ายจบ แล้วอยู่กับครอบครัวไปตลอด
> **01 เบี้ยเท่าเดิมทุกปี** — คิดจากอายุวันที่เริ่ม ไม่ขึ้นตามอายุ ไม่ต้องลุ้นทุกปีว่าจะจ่ายไหวไหม
> **02 จ่าย 9 หรือ 19 ปีแล้วจบ** — แต่ความคุ้มครองอยู่ถึงอายุ 99 จ่ายจบตอนยังทำงานอยู่ ไม่ต้องจ่ายตอนเกษียณ
> **03 ไม่ใช่จ่ายทิ้ง** — กรมธรรม์มีมูลค่าเงินสดสะสม ต้องใช้ฉุกเฉินก็เวนคืนหรือกู้ได้ตามเงื่อนไข

### บล็อก 4 — 2 เท่าช่วงที่ครอบครัวพึ่งคุณที่สุด
> ## ก่อนอายุ 60 ครอบครัวได้ 2 เท่าของทุน
> ช่วงที่ลูกยังเรียน บ้านยังผ่อน คือช่วงที่การจากไปกระทบหนักที่สุด แบบนี้จึงจ่ายสองเท่าในช่วงนั้น
> ทุน 1,000,000 → เสียชีวิตก่อนอายุ 60 ได้ 2,000,000 บาท ตั้งแต่อายุ 60 ถึง 99 ได้ 1,000,000 บาท

### บล็อก 5 — เลือกงวดชำระแบบไหนดี
ตัวอย่างชาย 35 ทุน 1,000,000 สามบรรทัดซ้อนกัน แต่ละบรรทัด: ชื่องวด · เบี้ยต่อเดือน (หรือต่อปีถ้ารายเดือนต่ำกว่าขั้นต่ำ) · รวมเบี้ยทั้งสัญญา · เหมาะกับใคร
- จ่าย 9 ปี — เหมาะกับคนที่อยากปิดภาระเร็ว จ่ายรวมน้อยที่สุด
- จ่าย 19 ปี — ตรงกลาง จ่ายจบก่อนเกษียณ (แนะนำ)
- ถึงอายุ 99 — เบี้ยต่อเดือนต่ำสุด สำหรับคนที่ต้องการทุนสูงด้วยงบต่อเดือนจำกัด
ตัวเลขทั้งหมดมาจาก `lifeProtectFacts()` ไม่พิมพ์มือ เมื่อตารางหมดอายุบล็อกนี้แสดงเฉพาะคำอธิบาย ไม่มีตัวเลข

### บล็อก 6 — ซื้อให้ลูก
> ## ของขวัญที่จ่ายจบก่อนลูกเรียนจบ
> ลูกแรกเกิด ทุน 1,000,000 จ่าย 19 ปี ราว N บาท/เดือน เบี้ยล็อกที่อายุแรกเกิดตลอด 19 ปี พอลูกอายุ 19 พ่อแม่จ่ายจบ ลูกมีประกันชีวิตติดตัวถึงอายุ 99 พร้อมมูลค่าเงินสดที่โตขึ้นทุกปี
> ผู้เยาว์ต้องมีผู้ชำระเบี้ย ทักมาให้เราจัดให้

### บล็อก 7 — คำถามที่พบบ่อย
1. **เบี้ยจะขึ้นไหม** — ไม่ขึ้น เบี้ยของแบบหลักคิดจากอายุวันที่เริ่ม และคงที่ตลอดระยะเวลาชำระ (ต่างจากสัญญาเพิ่มเติมโรคร้ายแรงที่ปรับตามอายุ)
2. **ต้องตรวจสุขภาพไหม** — ขึ้นกับอายุ ทุน และประวัติสุขภาพ ตัวแทนเช็กให้ได้ก่อนสมัคร เบี้ยที่แสดงเป็นเบี้ยมาตรฐาน
3. **จ่ายจบแล้วยังคุ้มครองอยู่ไหม** — อยู่ถึงอายุ 99 ไม่ต้องจ่ายอะไรเพิ่ม
4. **เวนคืนได้ไหม ได้เท่าไหร่** — ได้ตามตารางมูลค่าเวนคืนในกรมธรรม์ ชาย 35 ทุน 1 ล้าน จ่าย 19 ปี ที่อายุ 60 มีมูลค่าเงินสดราว N บาท (จากระบบ) เวนคืนแล้วความคุ้มครองสิ้นสุด
5. **ต่างจาก "มรดกเพื่อครอบครัว" ยังไง** — ชุดนั้นใช้แบบเดียวกันนี้เป็นฐานแล้วเพิ่มสัญญาโรคร้ายแรง ได้เงินก้อนตอนป่วยหนักด้วย แต่เบี้ยส่วนโรคร้ายแรงขึ้นทุกปีและคุ้มครองถึง 75 แบบนี้ไม่มีโรคร้ายแรง แต่เบี้ยไม่ขยับและจ่ายจบได้ ลิงก์ "ดูชุดมรดกเพื่อครอบครัว" ไป `/legacy`
6. **จ่ายไม่ไหวกลางทางทำยังไง** — ปรับลดทุนได้ หรือใช้มูลค่าเงินสดตามเงื่อนไข คุยกับตัวแทนก่อนขาดส่ง
7. **สมัครยังไง** — ทักแชท บอกอายุ ทุน และงวดที่ต้องการ ตัวแทนส่งใบเสนอฉบับเต็มให้ดูก่อนตัดสินใจ ไม่มีค่าใช้จ่าย

### บล็อก 8 — ข้อความกำกับ
เหมือน `/legacy` เปลี่ยนเฉพาะประโยคแรก:
> เบี้ยที่แสดงเป็นเบี้ยมาตรฐานโดยประมาณ คำนวณจากตารางเบี้ยฉบับ A2026-1 ใช้ประกอบการตัดสินใจเบื้องต้นเท่านั้น ไม่ใช่ใบเสนอราคาและไม่ใช่ส่วนหนึ่งของสัญญาประกันภัย
> มูลค่าเวนคืนเป็นไปตามตารางในกรมธรรม์ ความคุ้มครองและข้อยกเว้นเป็นไปตามที่ระบุในกรมธรรม์ การพิจารณารับประกันเป็นไปตามหลักเกณฑ์ของบริษัท
> ผู้ซื้อควรทำความเข้าใจรายละเอียดความคุ้มครองและเงื่อนไขก่อนตัดสินใจทำประกันภัยทุกครั้ง
