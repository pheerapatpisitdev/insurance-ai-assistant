# /fhc Financial Health Check — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A /fhc page (menu "Financial Health Check") that turns the agency's FHC questionnaire into scores, the five events tied to our priced plans, the /plan card, and an AI summary; usable by a customer alone or by an agent with them.

**Architecture:** Pure scoring in `src/lib/fhc/` (assumptions, health, summary, share) on top of the /plan engine (`toPlanInput` → `recommend` + `pickOrder`). Two server actions like /plan: `runFhc` (figures, fast) then `explainFhc` (AI summary + folded advice). Runs are logged anonymously in `ins_plan_runs` with `from: "fhc"`.

**Tech Stack:** Next.js 15 app router, React 19 client component, Tailwind (theme-legacy tokens), Vitest.

Spec: `docs/superpowers/specs/2026-09-25-fhc-design.md`.

### Task 2: `src/lib/fhc/assumptions.ts` and `health.ts`

**Files:** create both; test `tests/fhc/health.test.ts`

assumptions.ts — every rule named, Thai comments:
`DEFAULT_EXPECTANCY = 85`, `EMERGENCY_MONTHS = { green: 6, yellow: 3 }`, `SAVING_SHARE = { green: 0.2, yellow: 0.1 }`, `DEBT_YEARS = { green: 1, yellow: 3 }` (below green = green, up to yellow = yellow), `COVER_SHARE = { green: 1, yellow: 0.5 }`, `WorkAbility` + labels, `Relation` (child/spouse/parent/other) + labels, `EventKey` + `EVENTS` in FHC's order.

health.ts:
- `FhcInput` = the plan fields FHC shares (age, sex, income, expense, lifeCover, ciCover, healthNow, healthRoom, premiumsNow, hospital, lifeWant, retireAge, retireMonthly, pensionHave, budget) + `expectancy, work, cash, fixed, otherSaving, homeLoan, carLoan, otherDebt, taxFund, stocks, people: { relation, age }[]`.
- `cleanFhc(raw)`: runs `cleanInput` for the shared fields (its age/income sentences), then cleans the rest (money ≥ 0 capped; people ≤ 4, known relation, age 0–100; expectancy in LIFE_EXPECTANCY else 85; work known else "full").
- `figures(f)`: workYears (0 when work = none), moneyYears, incomeYear, lifetimeIncome, netMonth, savings, debts, invest, netWorth, emergencyTarget (expense × 6).
- `toPlanInput(f)`: savings = cash + fixed + other + stocks; retireLump = taxFund; children = ages of `child` rows; otherDependants = any other row; debts = sum; lifeExpectancy = expectancy.
- `scores(f)`: six `{ key, label, level, shown }` per the spec table; no divisor → level "none", shown "—"; debts 0 → green "ไม่มีหนี้".
- `events(f, scores, plan)`: five `{ key, name, level, lines }` — illness: health + CI offer lines; death: life offer line; accident / disability: fixed ปรึกษาตัวแทน lines, level none; jobLoss: emergency target line. An offer line is `product · เดือนละ X บาท` (fits/reduced), `product (งบไม่พอ)` (short), `มีพอแล้ว` (covered), `อายุนี้แบบที่มีรับไม่ได้` (unavailable).

Tests: figures on a worked example (35, retire 60, expectancy 85, income 40,000 → work 25, money 25, lifetime 12,000,000); work none → 0; `toPlanInput` children/dependants/no double count (stocks in savings, taxFund only in retireLump); each score at its thresholds (5.9 vs 6 months, 0.2 share, debt exactly 1 and 3 years, no income → none); events lines from a hand-made `PlanResult`.
