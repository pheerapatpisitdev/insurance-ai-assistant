# เชื่อมต่อเพจ Facebook

การเชื่อมต่อทำจากหน้า **แอดมิน → Messenger** ปุ่มเดียว ไม่ต้องคัดลอกโทเค็นเอง
แต่ต้องตั้งค่าใน Meta ให้ครบก่อนหนึ่งรอบ

## ทำใน Meta ครั้งเดียว

1. เข้า [developers.facebook.com](https://developers.facebook.com/apps/) → เลือกแอปของเรา
2. เมนูซ้าย **เพิ่มผลิตภัณฑ์ (Add product)** → เพิ่ม **Facebook Login**
3. ไปที่ **Facebook Login → การตั้งค่า (Settings)** ช่อง **Valid OAuth Redirect URIs**
   ใส่ทั้งสองบรรทัดนี้ แล้วบันทึก

   ```
   https://www.advisortool.app/api/facebook/connect/callback
   https://advisortool.app/api/facebook/connect/callback
   https://www.advisorx.biz/api/facebook/connect/callback
   https://advisorx.biz/api/facebook/connect/callback
   https://insurance-ai-assistant-pheerapatpisit.vercel.app/api/facebook/connect/callback
   ```

   ใส่ให้ครบทุกบรรทัด เพราะเปิดแอดมินจากโดเมนไหน Meta ก็ต้องรู้จักโดเมนนั้น
   เว็บนี้ผูกไว้หลายโดเมน ถ้าใส่ไม่ครบแล้วบังเอิญเปิดจากโดเมนที่ตกหล่น จะขึ้น URL blocked

   `localhost` ใส่ไม่ได้ Meta อนุญาตให้เองเฉพาะตอนแอปอยู่ในโหมดพัฒนา
   แอปนี้เผยแพร่แล้ว จึงทดสอบปุ่มนี้ในเครื่องไม่ได้ ต้องทดสอบบนเว็บจริง

   **ทำเสร็จแล้วเมื่อ 4 ก.ย. 2026** ทั้ง 5 บรรทัดบันทึกใน Meta เรียบร้อย

4. ที่ **App settings → Basic** คือที่มาของ `FB_APP_ID` กับ `FB_APP_SECRET`
   ทั้งสองตัวตั้งใน Vercel ไว้แล้ว ไม่ต้องทำอะไรเพิ่ม

5. ไปที่ **Facebook Login for Business → การกำหนดค่า** สร้างการกำหนดค่าใหม่
   เลือกโทเค็นแบบ **ผู้ใช้** (ไม่ใช่ผู้ใช้ระบบ) และติ๊กสิทธิ์ `pages_show_list`,
   `pages_messaging`, `pages_manage_metadata` แล้วเอา **ID การกำหนดค่า** ไปตั้งเป็น
   `FB_LOGIN_CONFIG_ID` แอปแบบธุรกิจไม่สนใจรายการสิทธิ์ที่ส่งไปใน URL
   หน้าขออนุญาตจะขอแค่ชื่อกับรูป แล้วจบด้วย "ไม่ได้เป็นแอดมินเพจไหนเลย"
   ถ้าไม่มีข้อนี้

   **ทำเสร็จแล้วเมื่อ 4 ก.ย. 2026** การกำหนดค่า ID 1600660545122340 ตั้งใน Vercel แล้ว

## เชื่อมต่อ

**สถานะปัจจุบัน (4 ก.ย. 2026)** เชื่อมต่อเพจ **LuckyPlanner โชคดีที่มีแพลน**
(ID 105982528649026) ผ่านปุ่มนี้แล้ว โทเค็นอยู่ในฐานข้อมูล ตัวแปร
`FB_PAGE_ACCESS_TOKEN` ใน Vercel ไม่ได้ใช้แล้ว ลบทิ้งได้เมื่อสะดวก


เปิดหน้าแอดมิน → Messenger → กด **เชื่อมต่อกับ Facebook** → เข้าสู่ระบบด้วยบัญชี
ที่เป็นแอดมินเพจ → อนุญาตสิทธิ์ → เลือกเพจ (ถ้ามีหลายเพจ) จบ

ระบบจะทำให้เองสามอย่าง

- แลกโค้ดเป็นโทเค็นอายุยาว แล้วดึงโทเค็นของเพจ ซึ่งเป็นชนิดที่**ไม่หมดอายุ**
- เก็บโทเค็นแบบเข้ารหัสไว้ในฐานข้อมูล ไม่ผ่านหน้าจอและไม่อยู่ใน URL
- สมัครรับเหตุการณ์ `messages` ให้เพจส่งข้อความเข้ามาที่ระบบเรา

## สิทธิ์ที่ขอ

| สิทธิ์ | ใช้ทำอะไร |
| --- | --- |
| `pages_show_list` | ดูรายชื่อเพจที่คุณเป็นแอดมิน เพื่อให้เลือก |
| `pages_messaging` | อ่านและตอบข้อความในนามเพจ |
| `pages_manage_metadata` | สมัครรับข้อความจากเพจเข้าเว็บฮุก |

ขอเท่านี้ตั้งใจให้น้อยที่สุด เวลายื่น App Review จะได้ตรวจน้อยรายการ

## ยกเลิกการเชื่อมต่อ

ปุ่ม **ยกเลิกการเชื่อมต่อ** ในหน้าเดียวกัน จะสั่งให้เพจหยุดส่งข้อความมาก่อน
แล้วค่อยลบโทเค็นทิ้ง กดเชื่อมต่อใหม่ได้ตลอด

## ถ้าเชื่อมต่อไม่ผ่าน

| ข้อความที่เห็น | สาเหตุ |
| --- | --- |
| ยังไม่ได้ตั้งค่า FB_APP_ID | ยังไม่ได้ใส่ App ID ใน Vercel |
| ลิงก์เชื่อมต่อหมดอายุ | เปิดค้างไว้เกิน 10 นาที กดใหม่ |
| URL blocked / redirect URI ไม่ถูกต้อง | โดเมนที่เปิดอยู่ยังไม่อยู่ในรายการข้อ 3 |
| บัญชีนี้ไม่ได้เป็นแอดมินเพจไหนเลย | เข้าสู่ระบบผิดบัญชี |
