# เปิดบอทตอบแชทเพจ — ทำอะไรบ้าง ตามลำดับ

โค้ดฝั่งเราพร้อมแล้ว เหลืองานบนเว็บของ Meta กับการตั้งค่าบน Vercel
ทำตามข้อล่างนี้ทีละข้อ ข้ามข้อไหนไม่ได้ ข้อที่เคยทำไว้แล้วมีหมายเหตุกำกับ

เพจ **LuckyPlanner โชคดีที่มีแพลน** (ID 105982528649026)
แอป **ai chet** (ID 1624098972401227)

---

## 1. ตรวจว่าแอปกับเพจยังอยู่ด้วยกัน

เข้า [developers.facebook.com/apps](https://developers.facebook.com/apps/) เปิดแอป `ai chet`
แล้วดูว่าแอปนี้กับเพจ LuckyPlanner ยังอยู่ใต้พอร์ตโฟลิโอธุรกิจ **Luckyplanner** เดียวกัน

ข้อนี้สำคัญเพราะมันคือเหตุผลที่บอท **ตอบคนทั่วไปได้โดยไม่ต้องยื่น App Review**
(ทดสอบกับบัญชีที่ไม่มีบทบาทในแอปแล้วเมื่อ 4 ก.ย. 2569 บอทตอบทันที)
ถ้าวันหนึ่งจะเอาบอทไปตอบเพจของตัวแทนคนอื่นที่ไม่ได้อยู่ใต้พอร์ตโฟลิโอนี้ ต้องยื่น App Review ก่อน
ซึ่งต้องผ่านการยืนยันธุรกิจและ Tech Provider ตามลำดับ

## 2. ตั้งตัวแปร 4 ตัว

เอาค่าจาก **App settings → Basic** ของแอป

| ตัวแปร | ได้มาจากไหน |
| --- | --- |
| `FB_APP_ID` | App settings → Basic → App ID |
| `FB_APP_SECRET` | App settings → Basic → App secret (กด Show) |
| `FB_VERIFY_TOKEN` | **เราตั้งเอง** พิมพ์อะไรก็ได้ที่เดาไม่ได้ เช่นสตริงสุ่มยาว ๆ จำไว้ใช้ข้อ 3 |
| `FB_LOGIN_CONFIG_ID` | ได้จากข้อ 4 |

ตั้งสองที่

- ในเครื่อง: ไฟล์ `.env.local`
- บน Vercel: Project → Settings → Environment Variables ใส่ให้ครบทั้ง Production, Preview, Development

> ⚠️ `FB_APP_SECRET` ถูกใช้เข้ารหัสโทเค็นเพจและใช้ทำรหัสแฮชของผู้ส่งด้วย
> ถ้าเปลี่ยนค่านี้ บทสนทนาเก่าจะอ่านไม่ออกและต้องเชื่อมเพจใหม่

## 3. ตั้ง Webhook

ในแอป → **Messenger → Settings → Webhooks** (หรือเมนู Webhooks)

- Callback URL: `https://www.advisortool.app/api/facebook/webhook`
- Verify token: ค่าเดียวกับ `FB_VERIFY_TOKEN` ในข้อ 2
- กด Verify and save

> ต้อง deploy ตัวแปรขึ้น Vercel **ก่อน** กดปุ่มนี้ ไม่งั้น Meta จะทักกลับมาเจอค่าว่างและไม่ผ่าน

แล้วสมัครรับเหตุการณ์ของเพจ ให้ติ๊กสี่อย่าง

- `messages` — ข้อความที่ลูกค้าพิมพ์
- `messaging_postbacks` — ปุ่มที่ลูกค้ากด
- `message_echoes` — **สำเนาข้อความที่เพจส่งออก**
- `messaging_referrals` — **ที่มาของแชท** ตอนลูกค้าเปิดแชทจากโฆษณาหรือลิงก์ m.me ระบบจึงรู้ว่าบทสนทนานี้มาจากโฆษณาชิ้นไหน

`message_echoes` ไม่ได้มีไว้ตอบใคร แต่เป็นทางเดียวที่ระบบจะรู้ว่า **คุณเข้าไปพิมพ์ตอบเอง**
แล้วบอทจะเงียบในห้องนั้น 24 ชั่วโมง ถ้าไม่ติ๊กข้อนี้ บอทจะพูดแทรกคุณ

หน้า **แอดมิน → Messenger** มีปุ่มสมัครรับเหตุการณ์ใหม่ให้กดได้เหมือนกัน
เพจที่เชื่อมไว้ก่อนหน้านี้ต้องกดหนึ่งครั้งเพื่อเพิ่ม `message_echoes` และ `messaging_referrals`

## 4. ตั้ง Facebook Login

**Add product → Facebook Login** แล้วไปที่ **Facebook Login → Settings**
ช่อง Valid OAuth Redirect URIs ใส่ให้ครบทุกบรรทัดที่จะใช้เปิดหน้าแอดมิน

```
https://www.advisortool.app/api/facebook/connect/callback
https://advisortool.app/api/facebook/connect/callback
```

`localhost` ใส่ไม่ได้ Meta ให้เฉพาะตอนแอปอยู่ในโหมดพัฒนา แอปนี้เผยแพร่แล้ว
**จึงต้องกดปุ่มเชื่อมต่อบนเว็บจริง ไม่ใช่บนเครื่อง**

จากนั้นไปที่ **Facebook Login for Business → การกำหนดค่า** สร้างการกำหนดค่าใหม่

- ชนิดโทเค็น: **ผู้ใช้** (ไม่ใช่ผู้ใช้ระบบ)
- สิทธิ์: `pages_show_list`, `pages_messaging`, `pages_manage_metadata`

เอา **ID การกำหนดค่า** ที่ได้ไปตั้งเป็น `FB_LOGIN_CONFIG_ID` ในข้อ 2
(ค่าเดิมที่เคยใช้คือ `1600660545122340` ถ้ายังอยู่ก็ใช้ค่านั้นได้)

แอปแบบธุรกิจไม่สนใจรายการสิทธิ์ที่ส่งไปใน URL ถ้าไม่มีข้อนี้
หน้าขออนุญาตจะขอแค่ชื่อกับรูป แล้วจบด้วย "ไม่ได้เป็นแอดมินเพจไหนเลย"

## 5. เชื่อมเพจ

เปิด `https://www.advisortool.app/admin/messenger` → กด **เชื่อมต่อกับ Facebook**
→ เข้าสู่ระบบด้วยบัญชีที่เป็นแอดมินเพจ → อนุญาตสิทธิ์ → เลือกเพจ

ระบบทำให้เองสามอย่าง

- แลกโค้ดเป็นโทเค็นอายุยาว แล้วดึงโทเค็นของเพจ ซึ่งเป็นชนิดที่ **ไม่หมดอายุ**
- เก็บโทเค็นแบบเข้ารหัสไว้ในฐานข้อมูล ไม่ผ่านหน้าจอ ไม่อยู่ใน URL
- สมัครรับเหตุการณ์ทั้งสี่ให้เพจ

หน้าเดียวกันจะบอกสถานะจาก Meta ว่าโทเค็นใช้ได้ไหม เพจส่งข้อมูลมาแล้วหรือยัง และรับเหตุการณ์อะไรอยู่บ้าง

## 6. ทดสอบ

1. ใช้บัญชี Facebook ที่ **ไม่มีบทบาทใดในแอป** ทักเพจว่า "สนใจครับ" — ต้องได้คำทักกลับพร้อมคำถาม อายุ/เพศ/ทุน
2. พิมพ์ต่อว่า "ชาย 35 ล้านนึง" — ต้องได้ใบเสนอราคาเต็มแล้วตามด้วยการ์ดรูป
3. เปิด `https://www.advisortool.app/api/health` — ต้องเห็น `"messenger": true`
4. เข้าไปพิมพ์ตอบเองจากกล่องข้อความของเพจ แล้วให้บัญชีทดสอบทักมาอีก — **บอทต้องเงียบ**

## ถ้าไม่ได้ผล

| อาการ | สาเหตุที่พบบ่อย |
| --- | --- |
| กด Verify and save แล้วไม่ผ่าน | ยังไม่ได้ deploy `FB_VERIFY_TOKEN` ขึ้น Vercel หรือพิมพ์ไม่ตรงกัน |
| กดปุ่มเชื่อมต่อแล้วขึ้น URL blocked | Redirect URI ในข้อ 4 ไม่ครบโดเมนที่กำลังเปิดอยู่ |
| ล็อกอินผ่านแต่บอกว่าไม่ได้เป็นแอดมินเพจไหนเลย | ยังไม่ได้ตั้ง `FB_LOGIN_CONFIG_ID` |
| ลูกค้าทักแล้วบอทเงียบ | ดูหน้าแอดมิน → Messenger ว่า "เพจส่งข้อมูลมาที่แอปนี้แล้ว" หรือยัง |
| บอทพูดแทรกตอนเราตอบเอง | ยังไม่ได้รับเหตุการณ์ `message_echoes` กดปุ่มสมัครรับใหม่ในหน้าแอดมิน |
| บอทตอบว่าระบบผู้ช่วยปิดชั่วคราว | ใช้งบ AI ของเดือนนั้นครบแล้ว ปรับเพดานได้ที่ แอดมิน → AI |
